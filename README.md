#  Heart Disease Risk Predictor

A Machine Learning project that predicts the risk of heart disease using patient health data.

##  Tech Stack
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- SHAP

## 📊 Features
- Data Preprocessing
- Logistic Regression
- Random Forest Classifier
- Model Evaluation
- SHAP Explainability

## ▶️ Usage
1. Place `heart.csv` in the project folder.
2. Open `predict.ipynb`.
3. Run all cells.

## 📌 Dataset
Heart Disease UCI Dataset
